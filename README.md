# Messenger-Android

Личный проект для мессенджера. Поддерживает аутентификацию, регистрацию, хранение токенов, просмотра и 
редактирования профиля. Токены хранятся в Data Store.

## Стек технологий

- **Jetpack Compose** — декларативный UI
- **Hilt** — внедрение зависимостей
- **Coroutines + Flow** — асинхронность и реактивность
- **Navigation Compose** — навигация между экранами
- **Material 3** — дизайн-система
- **Data Store** — хранение токенов
- **Ktor** — асинхронный клиент для серверного общения

Архитектура: **MVVM + Clean Architecture**.

## Требования

- **Android Studio** Meerkat (2025.1) или новее
- **JDK 11+**
- **Android SDK 36** (установится автоматически через SDK Manager)
- Устройство или эмулятор с **Android 9.0 (API 28)** или выше

## Release APK

Актуальный release apk находится в `app/release/`

## Сборка и запуск

1. Склонировать репозиторий и открыть корневую папку проекта в Android Studio.
2. Дождаться завершения Gradle Sync.
3. Выбрать конфигурацию **app** и нажать **Run**.

Сборка release-APK через терминал:

```bash
./gradlew assembleRelease
```

Собранный APK появится в `app/build/outputs/apk/release/`.

## Структура проекта

```
├── app/                     # Точка входа приложения (App, общие DI-модули)
├── data/                    # Ktor клиент, API services, реализация репозиториев, Hilt-модули
├── domain/                  # Бизнес-логика: модели, use cases, интерфейс репозитория
├── presentation/            # MainActivity, экраны, навигация, тема (Material 3), цвета, общие UI-компоненты
└── gradle/libs.versions.toml  # Централизованное управление версиями зависимостей
```
